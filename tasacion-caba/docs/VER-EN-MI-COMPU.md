# Cómo ver Plano Base en tu compu

Necesitás tener instalado **Node.js** (versión 20 o más nueva): https://nodejs.org (botón "LTS").

1. Bajá el proyecto y entrá a la carpeta `tasacion-caba`.
2. En una terminal, dentro de esa carpeta, escribí una línea por vez:

       npm install
       npm run dev

3. Abrí en el navegador: http://localhost:4321
4. Para apagarlo: `Ctrl + C` en la terminal.

Para verlo como en un celular: en Chrome o Edge apretá `F12` y después el ícono de celular/tablet.

Nota: la barra oscura que aparece abajo es de desarrollo; en la web publicada no está.
